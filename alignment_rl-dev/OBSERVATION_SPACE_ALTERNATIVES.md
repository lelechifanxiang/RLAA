# 波前/PSF作为观测空间的可行性分析

## 🔬 计算流程对比

### 当前方案：MTF观测
```
光线追迹 → PSF → LSF → FFT → OTF → MTF (30个值)
          ↑              ↑
      GPU计算~20ms    GPU FFT~5ms
```

### 备选方案1：PSF观测
```
光线追迹 → PSF (128×128×5场 = 81,920个值)
          ↑
      GPU计算~20ms（已包含在当前流程中）
```

### 备选方案2：波前观测
```
光线追迹 → 波前RMS/Zernike系数 (5场×N项 ≈ 50-100个值)
          ↑
      需额外计算波前拟合~10-15ms
```

---

## ⚖️ 三种观测空间对比

| 维度 | 当前MTF | PSF | 波前 |
|-----|---------|-----|------|
| **观测维度** | 30 | 81,920 | ~50-100 |
| **计算时间** | 25ms | 20ms | 30-35ms |
| **信息量** | ⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| **直观性** | ⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐⭐ |
| **训练难度** | 中 | 高 | 中 |

## 📊 详细分析

### 方案1：PSF作为观测空间

#### 优点
✅ **信息最丰富**
- PSF包含完整的成像信息
- 包含空间分布细节（MTF只有频率信息）
- 理论上能推导出所有其他指标

✅ **计算更快**
- 省略了LSF投影+FFT+插值（~5ms）
- 直接使用已有的PSF张量

✅ **更底层的物理量**
- 更接近光学本质
- 可能帮助策略理解光学原理

#### 缺点
❌ **观测维度爆炸**
```python
当前MTF：10步 × 30值 = 300维
改用PSF：10步 × 81,920值 = 819,200维

策略网络输入：819,200维 → 需要卷积网络处理
```

❌ **训练困难**
- 需要CNN处理图像输入
- 训练时间大幅增加（参数量增加）
- 需要大量样本才能学会"看"PSF图像

❌ **不够直观**
- PSF是复杂的2D图案
- 人类也难以直接从PSF判断对准状态
- 策略需要学习"PSF → 对准质量"的映射

#### 实现复杂度
```python
# 需要重新设计策略网络
observation_space = spaces.Box(
    low=0.0,
    high=1.0,
    shape=(10, 5, 128, 128),  # 10步历史 × 5视场 × 128×128 PSF
    dtype=np.float32
)

# 策略网络需要改为CNN
policy_network = CNN(
    input_channels=50,  # 10步×5场
    conv_layers=[64, 128, 256],
    fc_layers=[512, 256],
    output_dim=2
)
```

### 方案2：波前作为观测空间

#### 优点
✅ **信息更直观**
- 波前RMS直接反映光学质量
- Zernike系数对应具体像差（离焦、像散、彗差等）
- 工程师习惯用波前评估对准

✅ **维度适中**
```python
波前观测：10步 × (5场×10项Zernike) = 500维
比MTF略大(300维)，但比PSF小得多(819,200维)
```

✅ **物理意义明确**
- Z4 = 离焦 → 与dx/dy无关
- Z5 = 像散0° → 与dx/dy相关
- Z6 = 像散45° → 与dx/dy相关
- 策略可能更容易学习"哪些系数需要调整"

#### 缺点
❌ **需要额外计算**
- 当前流程不包含波前计算
- 需要在光瞳面拟合Zernike多项式（~10-15ms）
- 总计算时间增加50%

❌ **信息损失**
- Zernike拟合是近似（高阶像差被截断）
- 可能丢失一些细节信息

❌ **实现成本**
- 需要在optics_core中实现波前分析
- 需要集成到环境观测中

#### 实现复杂度
```python
# 观测空间仍为Box（可用MLP）
observation_space = spaces.Box(
    low=-10.0,  # Zernike系数范围
    high=10.0,
    shape=(500,),  # 10步 × 5场 × 10项Zernike
    dtype=np.float32
)

# 策略网络仍可用MLP（无需CNN）
policy_network = MLP([500, 256, 256, 2])
```

## 💡 推荐方案

### 短期（立即可做）：**保持MTF观测**

**理由**：
1. 当前问题的根源不是观测空间信息不足
   - 真正问题：初始范围太小（±0.5mm）+ 奖励失衡（5.0 bonus）
   - 添加状态信息(dx,dy)就能显著改进（只增加2维）

2. MTF已经是很好的观测
   - 30维紧凑高效
   - 直接反映成像质量（训练目标）
   - 已有4次训练验证可行性

3. 切换观测空间的风险
   - 需要重新调优所有超参数
   - PSF需要CNN（训练慢）
   - 波前需要新实现（开发成本）

### 中期（条件性尝试）：**增强MTF观测**

```python
# 方案A：MTF + 状态信息（推荐）
observation = [
    MTF历史(300维),
    动作历史(20维),
    当前状态(2维),     # 新增：(dx, dy)
]
# 总维度：322维（增加<1%）
```

```python
# 方案B：MTF + 任务上下文
observation = [
    MTF历史(300维),
    动作历史(20维),
    当前状态(2维),
    公差指纹(10维),     # 新增：零位附近梯度模式
]
# 总维度：332维（增加10%）
```

### 长期（实验性）：**波前观测**

**适合尝试的场景**：
1. MTF+状态信息仍无法解决问题
2. 有足够计算资源（波前计算+50%时间）
3. 想探索物理意义更明确的观测空间

**不推荐PSF观测**：
- 维度太大（800k+）
- 需要CNN（慢且难调）
- 信息冗余（大部分像素对对准不重要）

## 🎯 结论

### 直接回答你的问题

**Q1: 是否更快？**
- PSF：✅ 快5ms（省略MTF计算）
- 波前：❌ 慢10-15ms（需额外拟合）

**Q2: 信息是否更多？**
- PSF：✅ 信息最多（完整成像）
- 波前：✅ 物理意义更明确

**Q3: 是否值得切换？**
- 当前阶段：❌ **不建议**
  - 真正问题是环境配置（范围/奖励），不是观测空间
  - 切换成本高，收益不明确

- 未来阶段：⚠️ **可选尝试波前**
  - 前提：MTF+状态已尝试且仍不够
  - 波前的物理意义可能帮助策略学习
