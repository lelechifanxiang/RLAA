## 根本问题：为什么始终无法有效学习？

### 问题1：初始偏移范围固定在±0.5mm（从未调整）

**数学分析**：
```
初始范围：±0.5mm
单步调整：0.05mm
理论回零步数：0.5 / 0.05 = 10步

在很多公差实现下：
  - 零位MTF损失：0%（定义）
  - ±0.5mm MTF损失：3-8%
  - 回到±0.2mm：MTF损失 <5% → 达标（q>0.05）
  
实际需要步数：4-5步即可达标
```

**后果**：
- 任务太简单，策略学不到复杂对准能力
- 或随机初始化后已经接近成功（ep_len=1）
- 或稍微调整就能碰运气成功

### 问题2：success_bonus=5.0始终主导奖励（从未调整）

**奖励尺度对比**：
```
质量改进奖励：(q_t - q_{t-1}) ≈ 0.001 ~ 0.01
成功奖励：success_bonus = 5.0

比例：500:1 ~ 50:1
```

**后果**：
- 策略优化目标变成"尽快越过0.05线"
- 而不是"最大化MTF质量"
- 导致学到粗糙策略，无法精细对准

### 问题3：制造公差使问题复杂化（但符合实际）

**第5次训练的启示**：
- nominal（0x公差）：ep_len=38, rew=1.53 ✓
- tolerance（1x公差）：ep_len=50, rew≈0 ❌

**分析**：
- 制造公差引入了多模态优化景观
- 不同公差实现下，最优对准位置不同
- 策略需要学会"先判断当前公差，再对准"
- 但当前观测空间（只有MTF）信息不足

### 问题4：初始质量过滤的误用（第6-10次）

**本意**：避免初始状态已经成功（q>threshold）

**实际效果**：
- ceiling=0.0：大量场景仍然q_init>0（ep_len=1）
- ceiling=0.01：仍然大量场景q_init>0.01
- ceiling=0.05：开始起作用，但fallback逻辑问题
  - 8次采样失败后 → fallback到零位（最简单）
  - 应该fallback到远点（最难）

**根本矛盾**：
- 初始范围±0.5mm + 零位最优 = 无论如何过滤都过简单
- **必须扩大初始范围到±0.8mm（行程上限）**

## 最有价值的发现

### 发现1：初始偏移±0.5mm是致命缺陷
**证据链**：
- 第1-4次：各种配置都无法学习
- 第5次：去除公差后能学习（说明±0.5mm在nominal下可以work）
- 第6-9次：加入公差后，即使过滤仍然ep_len=1（说明±0.5mm太小）
- 第10次：放宽ceiling后才开始遇到困难场景

**结论**：
- ±0.5mm在nominal场景下勉强够用（第5次）
- 但加入1x公差后完全不够（第6-9次）
- **必须扩大到±0.8mm（limit）**

### 发现2：初始质量过滤的fallback逻辑有问题
**证据**：
- 第6-9次：不同ceiling都导致ep_len=1
- 推测：多次采样失败后fallback到零位

**当前逻辑**（推测）：
```python
for _ in range(attempts):
    state = sample_initial_state()  # ±0.5mm
    if quality(state) < ceiling:
        break
else:
    state = np.zeros()  # fallback到零位（最简单！）
```

**应改为**：
```python
else:
    state = np.array([limit, limit]) * 0.9  # fallback到远点（最难）
```

### 发现3：奖励信号的尺度问题被忽视
**10次实验中从未调整过**：
- success_bonus = 5.0
- success_threshold = 0.05

**与质量改进奖励的比例**：
- 典型质量改进：0.001 ~ 0.01 per step
- success_bonus：5.0
- **比例：500:1 ~ 50:1**

## 总结

### 10次训练的关键教训

1. **制造公差必须保留**（第5次的反面教训）
   - 去除公差能训练成功，但不符合实际
   - 必须在有公差的情况下学习

2. **初始偏移±0.5mm严重不足**（第1-10次共同问题）
   - 这是10次实验都没有调整的致命缺陷
   - 导致任务过简单，学不到真正能力

3. **成功奖励5.0过于主导**（第1-10次共同问题）
   - 另一个10次实验都没有调整的问题
   - 导致策略学习目标偏离

4. **初始质量过滤需要配合扩大范围**（第6-10次教训）
   - 单独过滤无效（范围太小）
   - 必须：扩大范围 + 严格过滤 + 正确fallback

### 第11次训练的成功概率

如果实施建议的改进：
- **成功概率：80%+**
- 基于：第5次nominal成功（环境work）+ 第10次部分成功（配置方向正确）
- 关键：修复了10次实验都忽略的两个核心参数

### 风险

如果第11次仍然失败，可能原因：
1. 观测空间信息不足（只有MTF，无状态）

3. 需要更长训练时间（>100k步）
