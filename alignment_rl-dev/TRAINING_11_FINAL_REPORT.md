## 问题诊断

### 熵系数崩溃原因
```python
ent_coef = 'auto'  # SAC自动调节

# 自动调节公式:
# ent_coef_loss = -log(ent_coef) * (entropy + target_entropy)
# 如果 entropy 持续低于 target_entropy
# → ent_coef 会指数下降 → 探索崩溃
```

**可能原因**:
1. 策略很快找到了"可行解"（虽然不是最优）
2. SAC的target_entropy设置过低（默认 -dim(action) = -2）
3. 观测空间信息不足以区分"接近最优"和"最优"

### 奖励偏低原因分析

**假设分析**:
```
如果 ep_rew_mean = 0.395, ep_len_mean = 30.5

总奖励 = 质量改进累积 + success_bonus × 是否成功
0.395 ≈ Σ(q_t - q_{t-1}) + 1.0 × P(success)

场景1: 未达标（成功率0%）
  0.395 = 质量改进累积
  → 平均每步改进 0.013

场景2: 部分达标（成功率~40%）
  0.395 = -0.6 + 1.0 × 0.4
  → 质量改进净值-0.6, 但40%时间达标补偿

需要查看评估日志确定实际成功率
```
