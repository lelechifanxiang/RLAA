## 问题诊断

### 为什么68%失败？

**假设分析**：

1. **公差太大，某些初始状态无法对准**
   ```
   严重公差 + 远离零位 (0.8mm) 
   → 某些组合下，50步内无法回到success_threshold
   ```

2. **策略陷入局部最优**
   ```
   熵系数0.001 → 几乎不探索
   → 策略固化在"不够好"的行为模式
   ```

3. **Success_threshold太严格？**
   ```
   q >= 0.05 → MTF提升5.1%
   在严重公差下可能过于严格
   ```

### 为什么有28%快速成功（1-10步）？

**可能原因**：

1. **某些公差实现下，初始采样恰好接近最优**
   ```
   虽然强制远离零位，但可能采样到"另一个好位置"
   ```

2. **策略学到了"识别简单情况"**
   ```
   当观测MTF较好时，策略快速收敛
   ```
