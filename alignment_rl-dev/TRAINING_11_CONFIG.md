# 第11次训练配置说明

## 改进内容

基于前10次训练的分析，本次训练修复了两个核心问题：

### 改进1：扩大初始范围 ⭐⭐⭐⭐⭐
```python
# 之前（第1-10次）
init_dx_mm = 0.5  # ±0.5mm
init_dy_mm = 0.5

# 现在（第11次）
init_dx_mm = 0.8  # ±0.8mm (覆盖完整动作空间limit)
init_dy_mm = 0.8

理由：
• 10次训练都使用±0.5mm，导致任务过简单
• 最大距离只有0.707mm，10-14步即可回零位
• 实际观察：第5次nominal训练平均38步（76%步数）
• 扩大到±0.8mm后，理论最少步数23步，预期35-45步
• 强制策略学习"长距离对准"能力
```

### 改进2：降低成功奖励 ⭐⭐⭐⭐⭐
```python
# 之前（第1-10次）
success_bonus = 5.0  # 隐式使用默认值

# 现在（第11次）
success_bonus = 1.0  # 显式设置

理由：
• 质量改进奖励：典型值 ±0.01 per step
• 之前成功奖励：5.0（比例500:1）
• 问题：策略被成功奖励主导，忽略质量改进梯度
• 改进后：成功奖励1.0（比例100:1）
• 策略会同时关注"达标"和"持续改进"
```

```

  ep_rew_mean: 0.2-0.5（质量改进为主）

  ep_len_mean: 15-25（高效对准）

```

### 不应该再看到

❌ ep_len_mean=1（过简单，立即成功）
❌ ep_len_mean=50（完全失败，超时）
❌ ep_rew_mean=0（无学习）
❌ ep_rew_mean=5.0（只有bonus）
❌ ent_coef→0.001（探索崩溃）

## 成功指标

训练成功的标志：
1. ✓ 出现明显学习曲线（ep_len和ep_rew都变化）
2. ✓ Episode长度在20-40之间（说明任务难度适中）
3. ✓ 平均奖励在1-2之间（质量改进+成功）
4. ✓ 成功率达到40-60%（评估时）
5. ✓ 熵系数保持在0.2-0.5（不崩溃）

如果成功：
→ 第12次可尝试更严格配置（公差2x、多视场等）
