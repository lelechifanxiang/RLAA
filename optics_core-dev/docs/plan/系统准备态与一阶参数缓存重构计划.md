# 系统 frame 与一阶数据缓存重构计划

## 目标

把当前分散在 `first_order.py`、tracing、layout、spot 中的实时推导，收敛成两类清晰的数据：

1. `FrameData`：每个 surface 的全局位姿。
2. `FirstOrderData`：TTL、EFFL、入口瞳位置、入口瞳半径等一阶量。

系统参数稳定后，用户显式执行：

```python
system.prepare()
```

随后追迹、layout、spot、aiming 都优先读取 `system.frame_data` 和 `system.first_order_data`，不再反复调用 `surface_position()` 或重复估计入瞳。

不在 `__init__()` 中自动计算，也不做隐式失效检查。修改参数、孔径、波长、视场后，由用户手动重新执行 `system.prepare()`。

## 命名和数据结构

不使用 `PreparedSystemData`。这个名字只描述“被准备过”，没有说明具体内容。

建议拆成两个公开成员：

```python
@dataclass(slots=True)
class FrameData:
    rotations: torch.Tensor  # [system_count, surface_count, 3, 3]
    origins: torch.Tensor    # [system_count, surface_count, 3]
    device: torch.device


@dataclass(slots=True)
class FirstOrderData:
    ttl: torch.Tensor
    effl: torch.Tensor
    entrance_pupil_z: torch.Tensor
    entrance_pupil_radius: torch.Tensor
```

`MultiOpticalSystem` 增加：

```python
self.frame_data: FrameData | None = None
self.first_order_data: FirstOrderData | None = None
```

变量名直接表达用途，避免 `prepared.first_order` 这类多一层语义中转。

## FrameData 计算

新增：

```python
compute_frame_data(system, device) -> FrameData
```

从 0 面开始正向传播每个表面的顶点 frame：

1. 第 0 面为恒等 frame。
2. 普通面使用当前 frame，随后沿当前 frame 的局部 z 轴推进 thickness。
3. CB 面先应用偏心、倾斜和 order 得到新 frame，再沿新 frame 的局部 z 轴推进 thickness。
4. 保存每个 surface 追迹时使用的 frame。

这样无 CB 系统自然退化为普通轴向坐标；有 CB 系统也能一次性得到每一面的真实位姿。反向追迹可以直接读取起始面的 frame，不需要临时恢复坐标链。

## FirstOrderData 计算

一阶量应在 `FrameData` 之后计算。

当前阶段的一阶量只需要近轴追迹，不需要真实光线瞄准，也不依赖全视场采样：

1. TTL：读取像面 frame origin。
2. ENPR：由入口瞳直径 aperture 直接给出。
3. ENPP：从 stop 面位置出发，用主波长近轴探测光线向物方追迹得到。
4. EFFL：在 0 视场使用固定小近轴高度或小近轴角度，按主波长追迹后反解。

注意：这里说“不依赖其他信息”，指不依赖 spot/layout/真实瞄准结果。它仍然依赖：

1. 主波长。
2. 材料在主波长的折射率。
3. `FrameData` 中的表面位姿。
4. 当前参数批量。

当前实现可以先复用真实 surface 追迹并使用极小近轴光线；后续如需更严格，可以单独实现 paraxial trace kernel，但不必作为第一阶段目标。

建议新增：

```python
compute_first_order_data(system, frame_data, device) -> FirstOrderData
```

计算完成后写入：

```python
system.first_order_data = first_order_data
```

## system.prepare()

`MultiOpticalSystem.prepare()` 的最小流程：

```text
1. compute_frame_data(...)
2. 写入 system.frame_data
3. compute_first_order_data(...)
4. 写入 system.first_order_data
5. 返回 self
```

准备过程中不新增隐藏 cache，不做自动判断是否过期。

## tracing 修改

`SequentialSurfaceRayTracer._trace_surfaces()` 改为读取 `system.frame_data`：

1. 如果缺少 `frame_data`，提示先执行 `system.prepare()`。
2. 起始 frame：

```python
frame_rotation = system.frame_data.rotations[:, start_surface]
frame_origin = system.frame_data.origins[:, start_surface]
```

3. 正向追迹后读取下一面的 frame。
4. 反向追迹后读取上一面的 frame。
5. `_core.py` 中临时的 `_axial_frame_at_surface()` 可以删除。

主循环只负责“当前面使用哪个 frame”，不再负责推导 frame。

## 其他模块修改

### first_order.py

保留：

1. `parameter_value()`
2. `surface_value()`
3. `stop_surface_index()`
4. `entrance_pupil_radius()`

替换：

1. `surface_position()` 改为兼容函数，优先读取 `system.frame_data.origins[:, surface_index, 2]`。
2. `total_track_length()` 改为读取像面 frame。
3. `compute_entrance_pupil()`、`compute_effective_focal_length()` 改为接收或读取 `FrameData`。

### spot_diagram.py

直接读取：

```python
system.first_order_data.entrance_pupil_z
system.first_order_data.entrance_pupil_radius
```

不再重复调用 `compute_entrance_pupil()`。

### layout_2d.py

表面位置读取 `system.frame_data`。当前阶段 layout 是否完整支持 CB 可以后置，但数据来源先统一。

### aiming.py

默认采样追迹直接读取 `system.first_order_data`。如果不存在，抛出异常提示先执行 `system.prepare()`。

## 实施步骤

### 阶段 1：FrameData

1. 新增 `FrameData`。
2. 实现 `compute_frame_data()`。
3. `MultiOpticalSystem` 增加 `frame_data` 和 `prepare()`。
4. 无 CB 测试：frame origin 的 z 与旧 `surface_position()` 一致。
5. CB 测试：现有 CB 正向追迹结果保持不变。

### 阶段 2：tracing 使用 FrameData

1. `_trace_surfaces()` 从 `system.frame_data` 读取 frame。
2. 正向和反向都用相邻 surface frame 更新。
3. 删除 `_axial_frame_at_surface()`。
4. 新增 CB 反向闭环测试。

### 阶段 3：FirstOrderData

1. 新增 `FirstOrderData`。
2. 实现 `compute_first_order_data()`。
3. `system.prepare()` 写入 `system.first_order_data`。
4. first order 回归测试改为验证 `system.prepare()` 后的数据。

### 阶段 4：分析模块切换

1. spot 读取 `system.first_order_data`。
2. layout 读取 `system.frame_data`。
3. aiming 读取 `system.first_order_data`。
4. 删除重复的实时入瞳计算。

## 单元测试计划

1. 普通双高斯：`FrameData` 与旧轴向位置一致。
2. 带 CB 双高斯：正向追迹继续和 Zemax 对齐。
3. 带 CB 双高斯：正向到像面，再反向追回前表面，验证闭环。
4. 双高斯 first order：EFFL、ENPP、ENPR 和 Zemax 对齐。
5. spot/layout：切换到缓存数据后结果不变。
6. device：`FrameData` 和 `FirstOrderData` tensor 与系统运行 device 一致。

## 注意事项

1. 第一阶段只缓存 frame 和一阶量，不打包全部曲率、材料、孔径参数。
2. 所有缓存数据使用 FP64 tensor。
3. 热路径中尽量减少 `surface_value()` 和 Python 对象树访问。
4. 暂时保留兼容入口，避免一次性改动过大。
