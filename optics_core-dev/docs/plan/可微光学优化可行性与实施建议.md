# 可微光学优化可行性与实施建议

## 目标

在现有 batch-first 光线追迹框架上，实现以 RMS 光斑半径为主要成像质量指标的光学参数优化，并支持：

1. 多个设计或多个初始点并行优化。
2. 基于 PyTorch 自动微分的一阶优化。
3. 基于阻尼最小二乘（DLS）的批量优化。
4. EFL、F/#、系统长度和结构边界等规格约束。

优化变量首先限定为曲率、厚度、空气间隔、偏心和倾斜等连续数值参数，不考虑玻璃牌号等离散变量。

## 可行性结论

当前逐面求交、折射、坐标变换和 RMS 统计主要由 FP64 Tensor 运算构成，算法主体具备可微基础；`design` 维度也适合表示多个独立优化任务。

但框架目前还不能端到端自动微分，主要原因是参数读取过程会把数值转换为 Python `float`，再使用 `torch.tensor(values)` 构造新张量，导致计算图断开。`BackendConfig.enable_autodiff` 当前也没有实际参与运行逻辑。

因此可以采用两条路线：

1. 近期使用“并行有限差分 + DLS”，直接复用现有多设计追迹能力。
2. 中期完成参数链路 Tensor 化，再支持原生反向传播和自动微分 Jacobian。

## 评价函数设计

### RMS 主目标

DLS 不应只接收最终的 RMS 标量，而应保留每条光线的横纵向像差作为残差：

```text
r_spot = [w1·dx1, w1·dy1, w2·dx2, w2·dy2, ...]
```

权重需要包含视场权重、波长权重和有效采样数归一化，使：

```text
RMS² ∝ r_spotᵀ r_spot
```

优化时使用 RMS² 对应的残差，避免在接近零时引入 `sqrt()` 的不良条件；输出结果仍报告 RMS 半径。

残差参考点需要与准确性对标保持一致，可选择主光线或质心。当前 spot 链路使用主波长主光线作为共同参考，因此多波长残差会保留横向色差。

### EFL 约束

定焦系统通常需要约束 EFL。若只最小化绝对 RMS 半径，优化器可能通过改变焦距、像高或成像比例获得更小光斑，但此时已经不再满足原始系统规格。

EFL 可作为一个归一化残差加入：

```text
r_efl = sqrt(weight_efl) · (EFL - target_efl) / scale_efl
```

“锁死 EFL”分为两种形式：

1. 软约束：使用较大但有限的权重，允许少量偏差，数值条件更稳定。
2. 严格约束：使用从属变量、等式约束 DLS 或拉格朗日乘子，使 EFL 精确满足目标。

第一版优先实现归一化软约束。只有明确需要严格保持焦距时，再增加等式约束，避免过早增加求解器复杂度。

### 常用附加约束

| 类型 | 常用参数 | 当前基础 |
| --- | --- | --- |
| 成像尺度 | EFL、放大率、像高 | EFL 已有；放大率和像高待实现 |
| 孔径规格 | working F/#、NA、入瞳直径 | working F/#、入瞳半径已有 |
| 空间约束 | BFL、工作距离、TTL | TTL 已有；BFL 待实现 |
| 远心与瞳 | 主光线像面角、入瞳/出瞳位置 | 瞳位置已有；主光线角待实现 |
| 映射与色差 | 畸变、轴向色差、垂轴色差 | 可由追迹扩展，尚无统一操作数 |
| 可制造性 | 中心厚度、边缘厚度、空气间隔、曲率、口径 | 中心厚度和曲率可直接读取；边缘厚度待计算 |

不应同时加入过多相关约束。例如入瞳直径固定时，EFL 与 F/# 高度相关，重复施加强约束可能使法方程病态。

边界约束可以统一表示为单边残差：

```text
r_lower = sqrt(weight) · relu((lower - value) / scale)
r_upper = sqrt(weight) · relu((value - upper) / scale)
```

## 并行一阶优化

参数张量建议使用以下形状：

```text
parameters: [design_count, parameter_count]
loss:       [design_count]
```

每个 design 表示一个独立系统或一个独立初始点。由于不同 design 之间没有数据依赖，对 `loss.sum().backward()` 执行一次反向传播，得到的每行梯度仍只对应本设计。

完成参数链路 Tensor 化后，可以直接实现批量 SGD 或 Adam。每轮优化需要：

1. 从当前参数重新计算 frame 和相关一阶量。
2. 并行追迹所有视场、波长和光瞳采样点。
3. 构造每个设计的残差和损失。
4. 反向传播并更新参数。

不同物理量的量纲差异较大，优化器不应直接操作原始数值。建议优化无量纲变量 `u`，再通过中心值和尺度映射到曲率、厚度、倾斜等物理参数。

## 并行阻尼最小二乘

DLS 使用 Gauss–Newton 近似 Hessian，不计算完整二阶导数。对每个设计求解：

```text
(JᵀJ + λD) Δp = -Jᵀr
```

其中 `J = ∂r/∂p`。`torch.linalg.solve()` 可以直接批量处理 `[design, parameter, parameter]` 法方程。

### 第一阶段：有限差分 Jacobian

对于 `B` 个设计和 `K` 个变量，将基准结构及每个参数的正负扰动展开为：

```text
[B, 1 + 2K, parameter]
```

这些结构可以通过现有多设计追迹一次或分 minibatch 计算，再使用中心差分构造 Jacobian。该方案不依赖自动微分改造，并且可以作为后续梯度正确性的基准。

有限差分每轮约需要 `2K+1` 个系统评价。虽然可以利用 GPU 并行，但不能对大量设计和大量变量无限展开，需要按原始 design 分 minibatch。

### 第二阶段：自动微分 Jacobian

残差数通常远多于优化变量，因此不适合对每个残差执行一次反向传播。完成函数化参数链路后，优先考虑：

1. 对参数方向使用 `jacfwd`。
2. 使用 JVP/VJP 计算法方程或矩阵向量积。
3. 按设计或光线分块累计 `JᵀJ` 和 `Jᵀr`，避免保存完整 `[B, residual, K]` Jacobian。

## 自动微分链路整改

需要完成以下最小修改：

1. 数值参数由 FP64 Tensor 保存，核心路径不再依赖 `list[list[Any]]`。
2. `surface_value()` 直接索引参数张量，禁止经过 `float()` 或重新构造 `torch.tensor()`。
3. 优化迭代中重新计算依赖参数的 `FrameData` 和 `FirstOrderData`，避免读取旧缓存。
4. 自动净口径只用于显示时无需进入优化计算图；固定光阑继续作为真实裁剪条件。
5. 实现 `MeritFunction.run()`，返回总 merit 和各项约束，同时保留供 DLS 使用的内部残差向量。

参数 Tensor 化后，应首先用中心有限差分检查 EFL、像面坐标和总损失对每个变量的梯度，再引入优化器。

## 数值风险

### 有效光线变化

当前 RMS 会忽略无效光线。如果优化器可以通过遮挡边缘光线降低 RMS，就可能得到虚假的更优结果。优化时应保持残差维度固定，并对失效光线增加惩罚，或者限制迭代过程中的有效光线集合不发生变化。

### 分段可微操作

光阑裁剪、全反射判断、求交根选择和有效性判断都是分段可微的。参数跨越这些边界时，梯度可能跳变。DLS 的步长接受、阻尼更新和参数边界需要抑制过大的跨边界更新。

### NaN 传播

无效光线当前会写入 NaN。即使后续使用 `torch.where()` 屏蔽，反向传播也可能受到无效分支影响。自动微分实现需要验证无效分支不会产生 NaN 梯度。

## 建议的最小验证案例

以 Double Gauss 为首个案例：

1. 选择 5～10 个连续变量，包括若干曲率、厚度和像面位置。
2. 使用多个视场和全部波长的 RMS² 残差。
3. 加入 EFL 目标，以及中心厚度和空气间隔下限。
4. 先运行有限差分 DLS，验证 merit、RMS 和 EFL 收敛。
5. 完成参数 Tensor 化后，对比自动微分与中心差分梯度。
6. 对同一组初始设计比较批量 Adam 和批量 DLS 的收敛速度与最终结果。

第一阶段不实现完整 Zemax 操作数集合、离散玻璃替换、全局搜索和完整 Hessian。先确保 RMS、EFL 和结构边界组成的最小评价函数可靠，再逐步扩展其他操作数。
