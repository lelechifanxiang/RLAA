# P0-4 一阶量补齐开发方案

> 状态：已完成。五文件异构 batch 与预存 Zemax 一阶量基准一致。

## 1. 目标

`FirstOrderData/FirstOrderResult` 为每个 design 稳定返回：

```text
effl, working_f_number, ttl, image_plane_distance, bfl, valid
```

全部数值 tensor 为 FP64 `[design]`，`valid` 为 bool `[design]`。本次不增加 CRA、像高、畸变或真实光线瞄准。

## 2. 字段定义

| 字段 | 定义 |
| --- | --- |
| `ttl` | 第一内部表面顶点到处方像面的轴向总长。 |
| `image_plane_distance` | 最后一折射面顶点到处方像面的距离。 |
| `bfl` | 最后一折射面顶点到主波长近轴焦点的距离。 |
| `valid` | 当前 design 的全部一阶结果是否有限且可用。 |

必须区分后两个距离。例如现有六片式文件的处方像面距离约为 `202 mm`，BFL 约为 `188 mm`，不能直接用最后一段厚度代替 BFL。

## 3. 计算方案

### 3.1 统一几何位置

`_FirstOrderCalculator` 初始化时确定最后一折射面索引，并从忽略 Coordinate Break 的一阶 `FrameData` 取得：

```text
z_first = 第一内部表面顶点位置
z_last  = 最后一折射面顶点位置
z_image = 处方像面位置
ttl = z_image - z_first
image_plane_distance = z_image - z_last
```

位置直接来自 batch frame tensor，避免再次按 design 遍历厚度参数。

### 3.2 近轴 BFL

前组 4 根 probe 只追迹到最后一折射面。使用其中正负高度的两根平行近轴光线计算：

```text
slope = l / n
z_focus = z_ray - x / slope
bfl = mean(z_focus - z_last)
```

`FrontParaxialData` 增加 `bfl`，与现有 EFL 共用同一对 probe 和有效样本，不增加新的追迹。入瞳位置仍由 stop 面的另外两根 probe 求解。

### 3.3 有效性

计算完成后统一检查 `ttl/effl/working_f_number/image_plane_distance/bfl`。任一数值非有限时：

- `valid=False`；
- 该 design 的上述五个数值统一置为 NaN；
- probe 斜率退化时直接判为无效，不用有限兜底值掩盖失败。

现有入瞳和出瞳字段不参与该有效掩码，保持各自的求解结果。

正常 ENPD、FLOA、FNUM 和有限物距系统沿用当前计算路径。

## 4. 代码调整

1. `_first_order_probes.py`：`FrontParaxialData` 和求解函数增加 BFL；
2. `first_order.py`：集中解析最后折射面、像面位置和最终 valid；
3. `system_state.py`：增加 `image_plane_distance`、`bfl`、`valid`，同步 `design_slice()`；
4. `analysis.py`：填充已有 `bfl`，增加 `image_plane_distance/valid`，并保证 `run()` 返回 tensor；
5. `tests/zemax/first_order.py`：通过 ZOSPy System Data 直接读取 BFL/Total Track，处方像面距离从 ZMX spec 读取。

不新增另一套一阶计算器，也不通过真实边缘光线或像面位置反算 BFL。

## 5. 测试方案

Contract 测试控制为一个：验证多 design 输出形状、`valid/NaN` 语义和 `design_slice()`，不为每个字段分别建测试。

Regression 使用两条链路：

1. 扩展现有 `test_basic_paraxial_focus.py`，对比 EFL、Working F/#、TTL、BFL 和处方像面距离；
2. 新增一个五文件异构 batch 回归，与预存的 Zemax System Data 逐 design 比较。基准保存到独立 JSON，日常测试不启动 Zemax。

Zemax 基准生成复用现有五文件加载和哈希校验逻辑，只在 ZMX 文件变化时重新生成。

## 6. 完成标准

- 必需一阶量均为 `[design]` tensor，不返回 `None`；
- BFL 与处方像面距离语义分离；
- 五文件 batch 的 EFL、Working F/#、TTL、BFL 与 Zemax 基准一致；
- 无效系统返回 NaN 和 `valid=False`；
- 现有一阶量、Spot、Wavefront、PSF/MTF 和全量测试无新增失败。
