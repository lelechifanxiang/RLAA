# 批量波前图功能开发计划

## 1. 目标

在已有 Huygens PSF / MTF 的基础上，增加一版可批量运行的 Wavefront Map 分析功能，并对标 Zemax 的 **Wavefront Map** 分析。

目标调用：

```python
result = system.analysis.wavefront(
    oc.WavefrontSettings(
        field_indices=(0, 1, 2),
        wavelength_indices=(1,),
        sample_count=32,
        save_path=None,
    )
).run()
```

首版只支持下面 4 类输入参数：

1. 视场索引 `field_indices`，支持多个视场并行。
2. 波长索引 `wavelength_indices`，支持多个单波长并行。
3. 采样率 `sample_count`，默认 32。
4. 保存路径 `save_path`。

不支持其他参数，例如：

1. `remove_tilt`
2. `use_exit_pupil`
3. `reference_to_primary`
4. `polarization`
5. `scale`
6. `sub_aperture`
7. `rotation`
8. `show_as`

这些 Zemax Wavefront Map 选项在首版中全部固定为内部常量，不作为公开接口。

---

## 2. 首版范围

### 2.1 支持内容

1. 多设计。
2. 多视场。
3. 多个单波长。
4. Wavefront Map OPD 网格，单位 waves。
5. RMS wavefront，单位 waves。
6. 有效 pupil mask。
7. 单设计图片导出。
8. 批量公差扫描脚本导出多张图片和性能统计。

### 2.2 不支持内容

1. 不支持 `wavelength_index=-1`。
2. 不支持全波长混合波前图。
3. 不支持 Zernike。
4. 不支持 tilt removal。
5. 不支持 polarization。
6. 不支持 exit pupil shape 显示。
7. 不支持用户自定义 pupil 坐标。

这里最重要的是波长语义：

```text
Wavefront Map 是单波长相位 / OPD 数据。
首版不提供 wavelength_index=-1，也不做多色混合。
如果需要多个波长，用户显式传入 wavelength_indices=(0, 1, 2)。
```

## 3. Zemax Wavefront Map 关键语义

### 3.1 Wavefront Map 显示的是 pupil 上的 wavefront error

Zemax 官方帮助说明 Wavefront Map 用来显示 pupil 上的 wavefront error，并且 `Sampling` 是用于采样 pupil 的 ray grid 大小，可选 32x32、64x64 等。

因此本项目的波前图应定义为：

```text
指定 field、指定 wavelength 下，pupil 网格上的 OPD / wavefront error。
```

### 3.2 首版固定评价表面为像面

Zemax Wavefront Map 有 `Surface` 选项，用于选择数据在哪个表面处评价。该选项可用于观察中间像面，但首版不暴露给用户，内部固定为：

```text
Surface = Image
```

因此本项目首版只输出像面处的 Wavefront Map，不支持用户选择任意表面编号。

这里需要区分两个概念：

1. `Surface=Image` 是 Zemax Wavefront Map 的评价表面。
2. exit pupil 出现在 OPD 参考球和 `Use Exit Pupil Shape` 显示选项中，不是一个需要用户选择的评价表面。

Zemax 的 OPD / Wavefront Map 通常以像面参考点和经过出瞳中心的参考球定义波前误差。也就是说，首版固定像面评价，并不等价于“不考虑出瞳参考语义”。

### 3.3 首版固定为 circular entrance pupil 显示坐标

Zemax Wavefront Map 有 `Use Exit Pupil Shape` 选项。官方帮助说明：

1. 选中时，显示形状会近似变形成从像点看到的 exit pupil shape。
2. 未选中时，图会缩放到 circular entrance pupil coordinates。

首版建议固定：

```text
Use Exit Pupil Shape = False
```

这样做的原因：

1. 输出坐标明确是圆形归一化 entrance pupil 坐标。
2. 可以避免为了显示 exit pupil shape 引入额外坐标变换或插值。
3. 更容易复用当前入瞳采样、追迹和 OPD 计算链路。
4. 更适合与 Zemax Wavefront Map 的数据网格做逐点对标。

需要注意：

```text
即使显示坐标固定为 entrance pupil coordinates，OPD 本身仍然是 Zemax Wavefront Map 定义下的波前误差；
它不是简单的入瞳平面几何高度，也不是 PSF 强度图。
```

如果后续需要对标 `Use Exit Pupil Shape=True`，应单独增加第二阶段功能：

1. 计算或读取 Zemax 使用的近似 exit pupil shape。
2. 将 OPD 数据映射到显示坐标。
3. 对 OpticsCore 输出图做同样坐标变换。

这不放入首版。

### 3.4 采样网格尺寸以 Zemax 原生 Wavefront Map 输出为准

Zemax Wavefront Map 的 `Sampling` 表示 pupil ray grid 大小。根据 Zemax 原生文本和原始数据，设置 `64x64` 时会报告：

```text
Pupil grid size: 64 by 64
```

并给出中心采样点所在的行列位置。因此首版实现约定为：

```text
sample_count = N
输出 wavefront map shape = N × N
```

这里不把 ZOSPy 文档中关于空首行 / 空首列和 `(N-1)×(N-1)` 的说明作为本项目的公开 shape 语义。ZOSPy wrapper 可能对 ZOS-API datagrid 做了后处理；本项目对标时应优先使用 Zemax Wavefront Map 原生输出，并在 Zemax helper 中记录 raw grid shape、中心点文字和坐标信息。

实现时不要直接复用普通 `SquarePupilSampler(nx=N, ny=N)` 并假设 `torch.linspace(-1, 1, N)` 就与 Zemax 一致。偶数采样下 Zemax 会采用自己的网格偏移语义，使中心采样点落在 pupil center 附近或正好包含中心点。该坐标规则需要通过 Zemax 对标单元测试锁定。

建议新增一个内部采样 helper：

```python
sample_zemax_wavefront_pupil(sample_count: int) -> SamplingResult
```

规则：

1. 生成 `sample_count × sample_count` 个普通 pupil 采样点。
2. 坐标顺序、中心点位置和 pupil mask 必须通过 Zemax Wavefront Map 对标测试确认。
3. 末尾仍追加 reference chief ray，供主光线参考使用。
4. reshape 时使用前 `sample_count ** 2` 个普通采样点。
5. 如果 ZOSPy wrapper 返回的数据和 Zemax 原生数据 shape 不一致，以 Zemax 原生数据为准。

### 3.5 固定 Zemax Wavefront Map 设置

Zemax helper 应固定以下设置：

```text
Analysis = Wavefront Map
Surface = Image
Field = field_index + 1
Wavelength = wavelength_index + 1
Show As = Surface
Rotation = 0
Sampling = f"{sample_count}x{sample_count}"
Polarization = None
Reference To Primary = False
Use Exit Pupil Shape = False
Remove Tilt = False
Scale = 1.0
Subaperture X = 0.0
Subaperture Y = 0.0
Subaperture R = 1.0
```

公开接口不暴露这些选项。

## 4. 与 PSF 的复用边界

波前图确实属于 PSF 的前置数据链路，但不能简单地“从 PSF 模块拿最终相位”。

当前 PSF 积分使用像面 OPL 和方向余弦直接构造像面平面波相位：

```text
OPL_j + dot(direction_j, P - P_image_j) - piston
```

Zemax Wavefront Map 则是 pupil 网格上的 wavefront error。两者共用：

1. field / wavelength 选择。
2. pupil ray 构造。
3. 追迹到像面。
4. 像面 OPL。
5. 主光线。
6. 有效 pupil mask。

但不共用：

1. PSF image grid。
2. Huygens 积分。
3. PSF 的多波长强度混合。
4. MTF 的 LSF / FFT。

因此推荐抽取一个较底层的 pupil trace helper，而不是让 Wavefront 依赖 `compute_huygens_psf_batch()`。

## 5. 推荐接口

### 5.1 WavefrontSettings

建议将当前 `WavefrontSettings` 改为：

```python
@dataclass(slots=True)
class WavefrontSettings:
    field_indices: Sequence[int] | None = None
    wavelength_indices: Sequence[int] | None = None
    sample_count: int = 32
    save_path: str | None = None
```

语义：

1. `field_indices=None` 表示全部视场。
2. `wavelength_indices=None` 表示主波长。
3. `wavelength_indices` 必须是普通非负索引序列。
4. 不接受 `-1`。
5. `sample_count=32` 时输出图大小为 `32×32`。
6. `save_path` 只支持单设计导图；多设计批量导图放在 example 脚本中。

如果用户传入 `wavelength_indices=(-1,)`，直接抛出：

```text
Wavefront Map 不支持 wavelength index -1；请显式传入具体波长索引。
```

### 5.2 WavefrontResult

建议扩展为：

```python
@dataclass(slots=True)
class WavefrontResult(AnalysisResult):
    opd: ArrayLike | None = None
    rms_wavefront: ArrayLike | None = None
    pupil_mask: ArrayLike | None = None
    pupil_x: ArrayLike | None = None
    pupil_y: ArrayLike | None = None
    field_indices: tuple[int, ...] = ()
    wavelength_indices: tuple[int, ...] = ()
    sample_count: int | None = None
    figure: Any | None = None
    axes: Any | None = None
    save_path: str | None = None
    detected_design_batch_size: int | None = None
    design_batch_size: int | None = None
    minibatch_count: int = 0
```

输出形状：

```text
opd:                (design, field, wavelength, map_y, map_x)
rms_wavefront:      (design, field, wavelength)
pupil_mask:         (design, field, wavelength, map_y, map_x)
pupil_x:            (map_y, map_x)
pupil_y:            (map_y, map_x)
map_y/map_x:        sample_count
```

输出单位：

```text
opd:           waves
rms_wavefront: waves
pupil_x/y:     normalized pupil coordinates, range [-1, 1]
```

`opd` 对标 Zemax Wavefront Map datagrid 的数值。

## 6. 推荐代码结构

### 6.1 新增 `optics_core/huygens_wavefront.py`

新增模块：

```text
optics_core/huygens_wavefront.py
```

职责：

1. `run_huygens_wavefront(system, settings)`。
2. `compute_huygens_wavefront_batch(...)`。
3. `iter_huygens_wavefront_design_batches(...)`。
4. `sample_zemax_wavefront_pupil(sample_count)`。
5. `plot_huygens_wavefront(...)`。

### 6.2 提取共享 pupil trace helper

建议新增：

```text
optics_core/huygens_pupil.py
```

内部数据结构：

```python
@dataclass(slots=True)
class HuygensPupilBatch:
    sample: SamplingResult
    trace_result: TraceResult
    pupil_coordinates: torch.Tensor
    valid_points: torch.Tensor
    chief_points: torch.Tensor
    image_points: torch.Tensor
    ray_directions: torch.Tensor
    opl: torch.Tensor
    wavelength_mm: torch.Tensor
    field_indices: tuple[int, ...]
    wavelength_indices: tuple[int, ...]
```

helper：

```python
compute_huygens_pupil_batch(
    system,
    field_indices,
    wavelength_indices,
    sample,
) -> HuygensPupilBatch
```

它只做：

1. field / wavelength 选择。
2. 通过给定 `SamplingResult` 构造入瞳光线。
3. 追迹到像面。
4. 整理有效 mask、主光线、OPL、方向余弦。

PSF 可以继续使用 `SquarePupilSampler`。

Wavefront Map 使用 `sample_zemax_wavefront_pupil()`。

这样复用的是追迹和数据整理，而不是强行共用同一个采样器。

### 6.3 OPD 计算

首版建议将已有 `_exit_pupil_reference_data()` 移到：

```text
optics_core/opd.py
```

并命名为：

```python
exit_pupil_referenced_opd(...)
```

Wavefront Map 使用该函数生成 OPD。

注意：

1. OPD 内部先用 mm。
2. 输出前除以对应波长 `wavelength_mm` 转为 waves。
3. 只对有限有效 pupil 点计算 RMS。
4. 不移除 tilt。

如果发现 Zemax Wavefront Map 与当前 `exit_pupil_referenced_opd()` 在非零视场存在系统性差异，优先检查：

1. Zemax `Use Exit Pupil Shape=False` 是否生效。
2. Zemax datagrid 有效区域是否正确裁掉空首行首列。
3. OPD reference 是否为当前波长 reference sphere。
4. pupil 坐标方向是否需要翻转。

## 7. 批量执行策略

波前图没有 PSF 的 `pupil × image` 复数相位张量，显存压力明显小于 PSF。

首版采用简单 design minibatch 策略：

1. CPU：默认一次计算全部设计。
2. CUDA：先尝试一次计算全部设计。
3. 如果发生 CUDA OOM，design batch size 减半重试。
4. batch size 为 1 仍失败时抛出明确错误。

不增加用户手动 batch size 参数。

一个 minibatch 内必须一次追迹全部目标视场和全部目标波长：

```text
design minibatch
    ↓
一次追迹 field × wavelength × pupil
    ↓
整理 OPD map
```

不要按视场或波长重复构造系统、重复 prepare。

## 8. Zemax helper 设计

新增：

```text
tests/zemax/wavefront_map.py
```

建议接口：

```python
fetch_zemax_wavefront_map_from_spec(
    spec,
    oss,
    *,
    sample_count: int,
    field_index: int,
    wavelength_index: int,
) -> ZemaxWavefrontMapReference
```

返回结构建议：

```python
@dataclass(slots=True)
class ZemaxWavefrontMapReference:
    opd: torch.Tensor
    pupil_x: torch.Tensor
    pupil_y: torch.Tensor
    rms_wavefront: float
    field_point: tuple[float, float]
    wavelength_um: float
    metadata: dict[str, Any]
```

Zemax helper 内部固定：

```python
zp.analyses.wavefront.WavefrontMap(
    field=field_index + 1,
    surface="Image",
    wavelength=wavelength_index + 1,
    show_as="Surface",
    rotation="Rotate_0",
    sampling=f"{sample_count}x{sample_count}",
    polarization=None,
    reference_to_primary=False,
    use_exit_pupil=False,
    remove_tilt=False,
    scale=1.0,
    sub_aperture_x=0.0,
    sub_aperture_y=0.0,
    sub_aperture_r=1.0,
)
```

读取数据时：

1. 优先读取 Zemax 原生 Wavefront Map datagrid，不主动丢弃行列。
2. 记录 `Nx`、`Ny`、`MinX`、`MinY`、`Dx`、`Dy` 等 raw grid 信息。
3. 记录 Zemax 文本输出中的 pupil grid size 和 center point 行列信息。
4. 输出 shape 应与 Zemax 原生 pupil grid size 一致。
5. 如果 ZOSPy wrapper 返回的 DataFrame shape 与原生 datagrid 不一致，测试 helper 需要明确打印差异，并以原生 datagrid 为对标基准。
6. 计算 RMS 时只统计有限值。

## 9. 回归测试

新增：

```text
tests/regression/test_huygens_wavefront_map_against_zemax.py
```

建议首批参数：

```text
sample_count = 32
field_index = 0, 1, 2
wavelength_index = primary
```

测试内容：

1. `result.field_indices` 正确。
2. `result.wavelength_indices` 正确。
3. `result.sample_count == 32`。
4. `opd` shape 与 Zemax 原生 Wavefront Map pupil grid size 一致。
5. Zemax 文本中的 center point 行列信息被打印出来。
6. `pupil_x/y` 与 Zemax datagrid 坐标一致。
7. `rms_wavefront` 与 Zemax datagrid RMS 一致。
8. 完整 OPD grid 最大绝对误差、平均绝对误差打印出来。

如果非零视场存在暂未对齐的系统误差：

1. 打印 field、wavelength、RMS、最大误差、平均误差。
2. 对该 case 使用 xfail。
3. field 0 主波长尽量严格通过。

## 10. 图片导出

单设计 `save_path` 导出一张图。

如果结果包含多个 field 或多个 wavelength，则 `save_path` 只允许在单 field、单 wavelength、单 design 情况下使用；否则抛错，批量导图交给 example 脚本。

图片建议：

1. 使用发散色图，例如 `RdBu_r`。
2. 色标以 0 waves 为中心。
3. pupil 外显示透明或固定背景色。
4. 标题包含 design、field、wavelength、RMS waves。

批量导出文件名：

```text
wavefront_design_0000_field_0_wave_1.png
```

不使用 `wave_all` 命名，因为不支持 `-1` 全波长。

6. `opd` 输出 shape 为 `(design, field, wavelength, sample_count, sample_count)`。
7. `rms_wavefront` 输出 shape 为 `(design, field, wavelength)`。
8. Zemax helper 明确调用 Wavefront Map，并固定 `UseExitPupil=False`、`RemoveTilt=False`。
9. Wavefront Map 与 Zemax 原生 datagrid 建立对标链路。
10. PSF / MTF 现有结果无变化。
11. 批量示例脚本能输出耗时、吞吐率和可选图片。
12. 代码没有引入用户手动 batch size 参数。

## 15. 风险与注意事项

### 15.1 Wavefront Map 与 PSF 的复用程度有限

Wavefront Map 可以复用 PSF 的追迹和 OPL 前置数据，但不能复用 PSF 的像面采样网格或多波长混合逻辑。

### 15.2 Zemax Wavefront Map 的采样需要单独确认

Zemax 偶数采样下存在中心点偏移语义，不能直接假设当前 `SquarePupilSampler` 与 Zemax 一致。必须通过 Zemax Wavefront Map 对标测试锁定坐标顺序、中心点位置和 pupil mask。

### 15.3 Use Exit Pupil Shape 暂不支持

首版固定 `UseExitPupil=False`。如果未来需要对标 `UseExitPupil=True`，需要增加 exit pupil display coordinate mapping，不能只改一个布尔值。

### 15.4 不做 tilt removal

`Remove Tilt` 在 Zemax 中等价于把 OPD 参考到 centroid。首版不支持，避免引入额外拟合和参考点差异。

### 15.5 不做 Zernike

Zernike 是 Wavefront Map 的后续消费者。等 Wavefront Map 对标稳定后再开发。
