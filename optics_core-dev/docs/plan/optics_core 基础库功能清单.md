# optics\_core 基础库功能清单

## 1. 文档目的

这份文档用于向潜在用户介绍 optics\_core 基础库的预期功能范围，并邀请相关研究者审阅其是否满足需求。

目标审阅对象主要包括：

1.  光学装配研究者
    
2.  计算光学研究者
    

我们希望通过这份文档确认两件事：

1.  当前规划的功能边界是否覆盖主要研究需求
    
2.  首版功能与后续扩展方向是否合理
    

## 2. 库定位

optics\_core 的定位是一个可复用的光学计算基础库，核心目标是从当前自动光学设计项目中剥离出通用的“GPU 并行光线追迹 + 像质评估”能力，供后续不同算法模块或研究工具调用。

这个库的重点不是自动优化策略本身，而是高性能的光学求值内核。它更适合作为下面这类系统的基础设施：

1.  自动光学设计中的评价内核
    
2.  光学系统分析工具
    
3.  计算光学中的前向仿真模块
    
4.  未来的图像形成与图像仿真模块
    

首版的核心方向分为三层：

1.  并行光线追迹
    
2.  像质评估
    
3.  图像仿真扩展
    

## 3. 首版会包含什么

从当前规划看，基础库拟纳入的能力包括“已有、可迁移模块”和“明确规划、待开发模块”两部分。

## 3.1 已有、可迁移模块

这些能力已经在现有项目中具备雏形或已有实现基础，目标是在接口剥离后以更通用的形式沉淀到基础库中。

### 3.1.1 几何曲面表示

首批将包含的曲面能力：

1.  球面
    
2.  偶次非球面
    

规划中的补充能力：

1.  近轴面
    

这些能力将构成基础库中曲面描述、法向计算、曲面求交和表面几何计算的基础。

### 3.1.2 材料模型

首批将包含：

1.  色散模型
    
2.  密度
    
3.  成本
    

规划中的补充能力：

1.  热膨胀系数
    

这部分既服务于追迹中的折射率计算，也服务于后续的物理约束评估和更完整的工程分析。

### 3.1.3 系统装配

首批将包含：

1.  光学系统表示
    
2.  曲面和材料序列的组装方式
    

规划中的补充能力：

1.  坐标间断支持
    

这部分的目标是把当前强耦合在自动设计代码内部的系统装配逻辑，变成可独立调用的显式接口。

### 3.1.4 光线采样

首批将包含：

1.  高斯采样
    
2.  平方采样
    

规划中的补充能力：

1.  六边采样
    
2.  杂乱采样
    

这些采样方式将服务于不同分析任务，例如入瞳估计、点列图分析、波前估计和图像仿真。

### 3.1.5 前向与后向追迹

首版将提供：

1.  前向光线追迹
    
2.  后向光线追迹
    
3.  面序列上的批量追迹能力
    
4.  面交点、出射方向和有效性判定
    

这部分是基础库的核心，目标是在 GPU 上支持多光线、多波长、多批次系统的并行求值。

### 3.1.6 入瞳估计与光线瞄准

首版将纳入：

1.  入瞳估计
    
2.  chief ray 相关估计
    
3.  光线瞄准相关能力
    

这一部分对多视场系统分析尤其重要，也是从“通用追迹器”走向“成像系统求值器”的关键能力。

### 3.1.7 像质评估与分析

首批拟纳入的像质分析能力包括：

1.  点列图
    
2.  波前图
    
3.  PSF
    
4.  MTF
    

规划中的补充能力：

1.  波前泽尼克系数分解
    
2.  对比度相关分析
    

从定位上看，这部分更偏“分析内核”，目标是能为自动设计、系统分析和计算成像前向模型提供统一的像质评估入口。

### 3.1.8 物理参数评估

首批拟纳入的工程和物理约束包括：

1.  一阶参数
    
2.  CRA
    
3.  畸变
    
4.  其他一系列操作数
    

这一层的目标是让基础库不仅能输出图像质量指标，也能输出与光学设计和工程可实现性相关的约束量。

## 3.2 已明确规划、待添加模块

这部分能力当前尚未作为可复用模块成型，但已经明确在基础库的功能规划中。

包括：

1.  多重结构
    
2.  公差计算
    
3.  膜层
    

其中，公差计算依赖坐标间断能力，因此不会作为最早期的首批交付内容，而更适合作为后续增强能力。

## 4. 希望审阅者重点反馈的问题

我们最希望潜在用户重点审阅以下内容：

1.  以上功能范围是否覆盖你们最常见的研究需求？如果用于你的研究方向，哪些模块是“首版必须有”的？
    
2.  对于几何曲面、材料模型、采样方式、追迹结果和像质分析结果，你最关心哪些输出？如果未来要接入你们的研究流程，还缺少哪些关键能力？
    
3.  对于装配、公差、坐标间断、膜层、热参数，你认为哪些是高优先级？
    
4.  对于波前、PSF、MTF、图像仿真，你认为哪些能力应更早进入首版或次版？
