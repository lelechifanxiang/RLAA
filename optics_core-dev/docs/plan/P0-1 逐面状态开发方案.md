# P0-1 逐面状态开发方案

## 1. 目标

一次追迹可选返回每个表面完成交互后的：

```text
x, y, z, l, m, n, opl, valid
```

入瞳光线的输出形状为 `[design, recorded_surface, field, wavelength, ray]`。状态使用全局坐标，表面轴只包含实际选择记录的面，且按追迹顺序排列。

本任务不包含失败原因分类、自动 minibatch 或 P0-3 续追辅助接口。

## 2. 接口设计

在 `rays.py` 增加：

```python
SurfaceStateSelection = Literal["all"] | tuple[int, ...]

@dataclass(slots=True)
class SurfaceTraceHistory:
    surface_indices: tuple[int, ...]
    x: ArrayLike
    y: ArrayLike
    z: ArrayLike
    l: ArrayLike
    m: ArrayLike
    n: ArrayLike
    opl: ArrayLike | None
    valid: ArrayLike
```

并扩展现有类型：

```python
class TraceOptions:
    record_surface_states: SurfaceStateSelection | None = None

class TraceResult:
    surface_history: SurfaceTraceHistory | None = None
```

语义如下：

- `None`：不记录，不产生历史 tensor；
- `"all"`：记录本次 `start_surface/stop_surface` 范围内的全部面；
- `tuple[int, ...]`：只记录指定的内部表面索引；
- `record_opd=False` 时 `surface_history.opl` 为 `None`；
- 输入面前的初始状态不放入历史。

`SurfaceIntersection` 继续只表示交点和法线，避免把“求交几何”与“表面后的光线状态”混在一起。

## 3. 追迹框架重构

当前 `_dispatch.py` 通过可变 `intersections` 列表记录交点，职责不够单一。本次一并调整：

```python
@dataclass(slots=True)
class SurfaceTraceStep:
    hit: SurfaceHit
    outgoing_ray: RayState
```

1. `_trace_surface_with_frame()` 删除 `intersections` 参数，统一返回 `SurfaceTraceStep`。
2. `_record_local_hit()` 改为纯坐标转换函数；删除 `_hits.py` 中的记录副作用。
3. `_trace_surfaces()` 成为唯一的结果编排位置，顺序执行：
   - 追迹单面并得到交点、出射位置和出射方向；
   - 累计到当前面的 OPL；
   - 计算当前 `valid`；
   - 按选项记录 intersection 和折射后状态。
4. 抽出统一的 `_ray_state_valid()`，最终状态与逐面状态使用同一有效性规则。
5. 历史开启时只暂存选中面的 tensor 引用，循环结束后沿 `dim=1` 一次 `torch.stack()`；不开启时不创建历史列表或额外 tensor。

这样普通球面、近轴面、像面和 Coordinate Break 都走同一记录路径，后续增加表面类型时无需复制历史逻辑。

## 4. 实施范围

- `optics_core/rays.py`：公共历史类型和追迹选项；
- `optics_core/tracing/_types.py`：单面追迹结果；
- `optics_core/tracing/_dispatch.py`：返回结果，移除记录副作用；
- `optics_core/tracing/_hits.py`：只保留求交计算；
- `optics_core/tracing/_core.py`：统一累计、筛选和堆叠历史；
- `optics_core/__init__.py`：导出公共类型；
- `tests/zemax/batch_ray_trace.py`：支持指定 Zemax 终止面；
- `tests/contract/`、`tests/regression/`：补充契约和 ZMX 回归。

不保留第二套旧历史实现，也不在 `cache` 或 `metadata` 中隐藏逐面状态。

## 5. 最小测试

1. 默认关闭时 `surface_history is None`，原有 `intersections` 行为不变；
2. 全面记录的形状和 `surface_indices` 正确，最后状态与 `TraceResult.rays/valid` 一致；
3. 每个中间状态与单独设置 `stop_surface` 的终态一致，包括 OPL；
4. 指定面记录只返回所选表面，异构 batch 与逐个 `design_view()` 一致；
5. 无效求交或全反射后的历史状态保持 NaN，`valid=False`；
6. 选取一个现有球面 ZMX，逐面比较 Zemax 的位置、方向和有效性；OPL 使用分段追迹等价性验证。

## 6. 完成标准

- 一次追迹可得到 12 个折射面后的完整 FP64 GPU tensor；
- 关闭历史记录时不增加逐面状态显存；
- 选择性记录、正向区间追迹和异构 design batch 行为一致；
- 现有全量测试、逐面等价测试和 Zemax 回归通过。
