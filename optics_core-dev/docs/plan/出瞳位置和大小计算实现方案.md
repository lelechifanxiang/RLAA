# 出瞳位置和大小计算实现方案

## 目标

为后续 OPL、OPD 和惠更斯 PSF 补齐一阶数据中的出瞳信息：

1. `exit_pupil_z`
2. `exit_pupil_radius`

出瞳属于系统准备态的一阶光学量，统一由 `system.prepare()` 计算并缓存。用户修改系统参数后，需要重新调用 `prepare()`。

## 参考代码启发

`reference/GYOptics/DiffOptics.py` 中有两条值得借鉴的思路：

1. `calc_order1_data()` 先用近轴递推计算 `effl`、`enpp`、`expp`、`enpd`
2. `calc_enp_all_fov()` 后续再用真实光线计算多视场 chief ray、入瞳瞄准和净口径

这说明一阶量和真实光线准备态应分层处理：

1. 出瞳位置和大小应在一阶计算中完成
2. 不应依赖后续真实光线净口径回填
3. 净口径计算可以作为 `prepare()` 的后一阶段，用于 layout、裁剪和显示

因此当前项目不建议让 `exit_pupil_radius` 依赖 `surface.aperture_radius` 的 auto 回填结果。

## 与 PSF 开发顺序的关系

建议保持下面的开发顺序：

1. 补齐出瞳位置和大小
2. 在追迹中累计 OPL
3. 基于出瞳参考计算 OPD
4. 在光线追迹和 OPD 基础上实现固定语义的惠更斯 PSF

不要直接跳到 PSF。出瞳和 OPD 都需要先单独和 Zemax 对齐，否则 PSF 误差来源会很难拆解。

## 基本定义

出瞳是 stop 面经后组光学系统在像方形成的近轴像。

因此：

1. `exit_pupil_z` 是 stop 面被后组系统成像后的像方位置
2. `exit_pupil_radius` 是 stop 半径乘以后组系统的近轴横向放大率
3. stop 半径不是自动净口径，也不应该依赖 `calculate_clear_apertures()`

当前项目孔径类型只支持 `entrance_pupil_diameter`。因此 stop 半径可以从入口瞳半径和前组系统的近轴放大率反解得到：

```text
entrance_pupil_radius = abs(front_magnification) * stop_radius
stop_radius = entrance_pupil_radius / abs(front_magnification)
exit_pupil_radius = abs(rear_magnification) * stop_radius
```

如果 stop 就在首面，则 `front_magnification = 1`，stop 半径等于入口瞳半径。

## 首版约束

首版只支持当前项目已经采用的一阶计算语义：

1. 忽略 Coordinate Break
2. 使用主波长
3. 使用近轴探测光线或等价近轴递推
4. batch-first，支持多设计并行
5. stop 面必须存在
6. 系统孔径类型只支持 `entrance_pupil_diameter`

`prepare()` 应保证 `FirstOrderData` 完整存在。分析模块不需要再写“缺少出瞳数据时兜底计算”的逻辑。

## 数据结构修改

扩展 `FirstOrderData`：

```python
@dataclass(slots=True)
class FirstOrderData:
    ttl: torch.Tensor
    effl: torch.Tensor
    entrance_pupil_z: torch.Tensor
    entrance_pupil_radius: torch.Tensor
    stop_radius: torch.Tensor
    exit_pupil_z: torch.Tensor
    exit_pupil_radius: torch.Tensor
```

是否暴露 `stop_radius` 可以再决定，但建议先保留。它是连接入口瞳和出瞳半径的中间一阶量，对后续调试很有价值。

## 推荐计算流程

### 1. 计算入口瞳

沿用当前 `compute_entrance_pupil(...)`：

1. `entrance_pupil_z`
2. `entrance_pupil_radius`

入口瞳半径直接来自系统孔径：

```python
SystemAperture(kind="entrance_pupil_diameter")
```

### 2. 计算前组横向放大率

入口瞳是 stop 面经前组系统在物方形成的像。当前入口瞳求解函数 `solve_entrance_pupil_from_probes(...)` 已经能返回 `pupil_magnification`。

建议改造 `compute_entrance_pupil(...)`，让它返回：

```python
entrance_pupil_z, entrance_pupil_radius, front_magnification
```

其中：

```text
front_magnification = entrance_pupil_height / stop_probe_height
```

如果 stop 位于首面，则：

```python
front_magnification = torch.ones_like(entrance_pupil_radius)
```

### 3. 反解 stop 半径

新增：

```python
def compute_stop_radius(
    entrance_pupil_radius: torch.Tensor,
    front_magnification: torch.Tensor,
) -> torch.Tensor:
    ...
```

计算：

```python
stop_radius = entrance_pupil_radius / torch.clamp(front_magnification.abs(), min=1e-12)
```

这一步只依赖一阶量，不依赖 `surface.aperture_radius`，也不依赖自动净口径。

### 4. 计算出瞳位置和后组放大率

新增：

```python
def build_exit_pupil_probe_rays(
    system,
    stop_position: torch.Tensor,
    probe_height: torch.Tensor,
) -> RayBundle:
    ...

def solve_exit_pupil_from_probes(...) -> tuple[torch.Tensor, torch.Tensor]:
    ...

def compute_exit_pupil(system, *, device=None, frame_data=None) -> tuple[torch.Tensor, torch.Tensor]:
    ...
```

从 stop 面出发，向像方正向追迹两根近轴探测光线：

1. 两根光线初始高度相同：`x = probe_height`
2. 两根光线斜率不同：`l/n = 0` 和 `probe_slope`
3. `y = 0`
4. 波长固定为主波长
5. `ignore_coordinate_breaks=True`

追迹范围：

```python
start_surface = stop_index + 1
stop_surface = len(system.surfaces) - 1
direction = "forward"
```

由两根出射近轴光线反解：

```python
slope = result.rays.l / result.rays.n
exit_pupil_z = z0 + (x1 - x0) / (slope0 - slope1)
exit_height = 0.5 * (
    x0 + slope0 * (exit_pupil_z - z0)
    + x1 + slope1 * (exit_pupil_z - z1)
)
rear_magnification = exit_height / probe_height
```

如果 stop 后面没有光学面，则：

```python
exit_pupil_z = stop_position
rear_magnification = torch.ones_like(stop_position)
```

### 5. 计算出瞳半径

```python
exit_pupil_radius = rear_magnification.abs() * stop_radius
```

### 6. 写入 FirstOrderData

`compute_first_order_data(...)` 中的顺序建议为：

1. 计算忽略 CB 的 `first_order_frame_data`
2. 计算 `ttl`
3. 计算 `effl`
4. 计算 `entrance_pupil_z/radius/front_magnification`
5. 计算 `stop_radius`
6. 计算 `exit_pupil_z/rear_magnification`
7. 计算 `exit_pupil_radius`
8. 返回完整 `FirstOrderData`

然后 `system.prepare()` 再进入 `calculate_clear_apertures()`，回填 auto surface 的净口径。

## 代码落点

建议只改三个位置：

1. `optics_core/system_state.py`
   - 扩展 `FirstOrderData`

2. `optics_core/first_order.py`
   - `compute_entrance_pupil(...)` 返回前组放大率
   - 新增 `compute_stop_radius(...)`
   - 新增 `build_exit_pupil_probe_rays(...)`
   - 新增 `solve_exit_pupil_from_probes(...)`
   - 新增 `compute_exit_pupil(...)`
   - 在 `compute_first_order_data(...)` 中写入出瞳数据

3. `tests/zemax/first_order.py`
   - 增加直接读取 Zemax 出瞳位置和出瞳半径的 helper

不建议新增独立 `exit_pupil.py`。出瞳属于一阶参数，放在 `first_order.py` 内更直接。


## 注意事项

1. 出瞳计算属于一阶近轴量，应和入口瞳、EFFL 一样忽略 CB。
2. `exit_pupil_radius` 不直接读取 stop 面 `aperture_radius`。
3. 自动净口径回填发生在一阶数据之后，不参与出瞳计算。
4. 如果后续支持 `float_by_stop_size`，再让 stop 半径直接来自 stop 面固定孔径；当前阶段不做。
5. OPD 和 PSF 模块只读取 `system.first_order_data.exit_pupil_z/radius`，不做兜底计算。
